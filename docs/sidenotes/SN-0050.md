Audit every test in the project against the stable ID contract pattern
documented in `rm-testing` §bUnit Component Smoke Tests. Replace
assertions that couple to raw HTML tags (`Find("h3")`, `Find("p")`) or
rendered text content with `Find($"#{Component.ElementId}")` assertions
against defined element IDs. The ID is the stable contract — survives
any tag, text, or CSS change.
