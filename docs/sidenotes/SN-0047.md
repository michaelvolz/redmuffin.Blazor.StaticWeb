Pre-commit tool-call gate that validates every `uses:` action in
workflow YAML files against the canonical `action.yml` at the pinned
release tag. For each action, fetches `action.yml`, extracts the
`inputs:` section, and cross-checks every `with:` key in the workflow.
Catches parameter naming mismatches — snake_case vs kebab-case,
renamed inputs between versions, unexpected parameters that are
silently ignored by the runner — before they reach production.

Writing a "never do this" rule in the skill only covers this specific
bug. A tool-call gate closes the entire category: any third-party
action parameter mismatch, now and forever.

Run before every commit that touches a workflow file. Could integrate
with `wrkflw` which already validates YAML syntax during `wrkflw
validate` — parameter schema validation is the missing piece.
