id: SN-0048
date: 2026-06-12
title: Fix Brave/Exa search rate limits — enforce retry with backoff, never drop rate-limited requests
status: pending
---

The Brave Search and Exa web search tools have severely limited API
call quotas per time window. The LLM fires them in rapid succession
without self-throttling and hits rate limits frequently. When a request
returns a 429, the agent does not wait and retry after 1-2 seconds —
it silently moves on or produces a failed response. This is not
acceptable. No rate-limited request can ever be ignored or discarded.

The fix must operate at the tool-call or plugin layer — never rely on
the LLM to voluntarily self-throttle (override failure, Rana 2026).
Every 429 response must trigger an automatic wait-and-retry with
exponential backoff, and the retried result must be returned to the
agent as if the original call succeeded on the first attempt.
