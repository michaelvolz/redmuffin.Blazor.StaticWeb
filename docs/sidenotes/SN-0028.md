The Release build of the main test project fails with NU1004 lock file drift
errors. The current workaround is using Debug config for coverage generation,
documented in tools/README.md with the comment "Release has lock file drift
issues."

We need to find the root cause of the lock file inconsistency (likely
`RestoreLockedMode` being enabled and the lock file containing stale
package references), fix it so Release builds work reliably, then remove
the Debug-only workaround comment from tools/README.md.
