# Move `.razor` into module projects (authorized — ApiHealth pilot)

**Disposition:** **authorized / in progress.** Lazy-load P0 is done
(implementation assembly deferred until `/api-health`; user-confirmed).
Product priority stays **initial page load** + feature correctness; total
size is secondary.

**What it is:** ship Blazor UI (`.razor` / page code-behind + page ViewModels)
from the `{Module}` RCL instead of the host `Features/` tree. Host stays
composition root, shell layout, nav chrome, and load-path infrastructure.

## Done (P0)

- `BlazorWebAssemblyLazyLoad` for `ApiHealth.dll`
- Navigate-time `LoadAssembliesAsync` + reflection factory (no static type root
  into the lazy impl)
- Host gate / load options / thin eager `GetHelloHandler`
- Release boot: `ApiHealth.wasm` only under `lazyAssembly`

## Big steps (this vertical — keep coarse)

1. **Module becomes RCL + owns the page** — **done**  
   `Modules/ApiHealth` is `Microsoft.NET.Sdk.Razor` (`net10.0`). Page +
   ViewModels live there. No host Common component refs (inline markup, same
   CSS hooks).

2. **Host stays load + composition only** — **done**  
   Gate, load options, eager `GetHelloHandler` remain on host. Router loads
   `ApiHealth.dll` on `/api-health` and feeds `AdditionalAssemblies`.

3. **Prove in one pass** — **in progress**  
   Host ApiHealth bUnit + handler tests green; module service tests green
   after cancel guard. Optional: cold path browser smoke when convenient.

4. **Stop — do not cascade**  
   Do not move Raindrop/Articles/Videos pages here. Next program vertical =
   Raindrop Mediator use cases (roadmap §6.3).

- Feature works on `/api-health`
