# Mutation `--update-manifest`

Differential mutation keeps a **manifest**: fingerprints (hashes) of methods already checked so the next run only mutates what changed. Upstream mutate4java/clj-mutate can rewrite that checklist from current source **without** applying mutants or running tests (`--update-manifest`). Local QualityGates still has `--mutate-all` (force full re-check) but not a manifest-only refresh.

**Why it exists:** after a big rename/refactor or a stale/wrong manifest, update fingerprints without a full mutation run.

**Why it is not urgent:** day-to-day bug catching already works (operators, kill rates, differential mode). This is Uncle Bob CLI UX parity and a workflow convenience, not a missing correctness gate. Live without it if you never babysit manifests by hand.
