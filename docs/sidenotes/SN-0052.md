# NsDepCop (not for now)

**Disposition:** not used for modularization or day-to-day work. Possible future task only.

**What it is:** open-source Roslyn analyzer that fails the build on illegal namespace dependencies (layering rules in config).

**Why parked:** this repo already enforces structure with the local **architecture** quality gate (allowed edges, cycles, zones). A second dependency enforcer would duplicate config and noise without clear gain.

**Production impact:** none if added later (analyzer/build-time only; not in the WASM publish output).

**Revisit when:** architecture gate cannot express a real namespace rule we need, or we want IDE-red underlines without running the CLI gate. Until then: ignore.
