preferred. We should have a guide instructing us to prefer LINQ over other
data retrieval, manipulation, selection, and listing approaches. Need to
check for pitfalls and drawbacks first (e.g., deferred execution, multiple
enumeration, allocations, ReadOnlySpan incompatibility).
