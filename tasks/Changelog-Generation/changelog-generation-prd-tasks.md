## Relevant Files

- `scripts/Generate-Changelog.ps1` - Main PowerShell script that orchestrates the changelog generation process
- `git-commits.txt` - Input file containing Git commit history one-liners (already exists)
- `CHANGELOG.md` - Output file containing the formatted changelog (generated by script)
- `config/changelog-config.json` - Configuration file for filtering rules and categorization patterns
- `.changelog-state` - State tracking file for incremental updates (generated by script)
- `scripts/modules/CommitParser.psm1` - PowerShell module for parsing commit messages
- `scripts/modules/CommitParser.Tests.ps1` - Unit tests for the CommitParser module
- `scripts/modules/FilterModule.psm1` - PowerShell module for filtering non-essential commits
- `scripts/modules/FilterModule.Tests.ps1` - Unit tests for the FilterModule
- `scripts/modules/CategorizationModule.psm1` - PowerShell module for categorizing commits into logical groups
- `scripts/modules/CategorizationModule.Tests.ps1` - Unit tests for the CategorizationModule
- `scripts/modules/ChangelogFormatter.psm1` - PowerShell module for formatting changelog entries and Markdown output
- `scripts/modules/ChangelogFormatter.Tests.ps1` - Unit tests for the ChangelogFormatter module
- `scripts/modules/FileGenerator.psm1` - PowerShell module for generating and writing changelog files
- `scripts/modules/FileGenerator.Tests.ps1` - Unit tests for the FileGenerator module
- `scripts/modules/UpdateModule.psm1` - PowerShell module for updating existing changelog files with duplicate detection
- `scripts/modules/UpdateModule.Tests.ps1` - Unit tests for the UpdateModule

### Notes

- Unit tests should be placed alongside the script files they are testing (e.g., `Generate-Changelog.ps1` and `Generate-Changelog.Tests.ps1` in the same directory).
- Use `Invoke-Pester` to run PowerShell tests. Running without parameters executes all `*.Tests.ps1` files found recursively.
- PowerShell modules (`.psm1`) should be placed in a `modules` subdirectory for better organization.
